  1. 多协议支持：

    不同于简单的全局代理，Shadowrocket允许用户设置复杂的规则来决定哪些流量走代理，哪些直连。例如，您可以设置仅国外网站走代理，国内网站直连，既保证了访问自由，又不影响本地网络速度。

详细搭建步骤

第一步：准备谷歌云环境

  1. 注册谷歌云账号并登录控制台
  2. 创建新项目并启用Compute Engine API
  3. 配置结算账户（注意利用免费试用额度）

第二步：创建虚拟机实例

  1. 选择地区：优先考虑靠近您物理位置的区域，如"asia-east1"(台湾)或"asia-southeast1"(新加坡)
  2. 机器配置：最低配置即可满足需求（1vCPU，1GB内存）
  3. 操作系统：推荐Ubuntu 20.04 LTS
  4. 防火墙设置：务必勾选允许HTTP和HTTPS流量

第三步：部署Shadowsocks服务

通过SSH连接到您的实例后，执行以下命令：

bash wget --no-check-certificate -O shadowsocks-all.sh https://raw.githubusercontent.com/teddysun/shadowsocks_install/master/shadowsocks-all.sh chmod +x shadowsocks-all.sh ./shadowsocks-all.sh 2>&1 | tee shadowsocks-all.log

安装过程中，您需要选择：
- 版本：推荐Shadowsocks-libev
- 密码：设置强密码
- 端口：建议使用443（HTTPS端口，较难被封锁）
- 加密方式：推荐chacha20-ietf-poly1305

第四步：优化服务器配置

为了突破深度包检测(DPI)，我们需要进行以下优化：

  1. 安装BBR加速：
    bash wget --no-check-certificate https://github.com/teddysun/across/raw/master/bbr.sh && chmod +x bbr.sh && ./bbr.sh

  2. 配置伪装：
    将Shadowsocks流量伪装成正常的HTTPS流量，可以使用v2ray-plugin或cloak等插件。

第五步：客户端配置

  1. 在iOS设备上安装Shadowrocket（需要非中国区Apple ID）
  2. 添加服务器配置：
    • 类型：Shadowsocks
    • 地址：您的谷歌云实例外部IP
    • 端口：安装时设置的端口
    • 密码：安装时设置的密码
    • 加密方式：与服务器一致
  3. 启用插件（如配置了v2ray-plugin）

常见问题解决

Q: 连接速度慢怎么办？
A: 尝试以下方法：
- 更换服务器区域
- 启用BBR加速
- 尝试不同的加密方式（如更换为aes-256-gcm）

Q: 突然无法连接了？
A: 可能的原因：
- IP被封锁：更换服务器外部IP
- 端口被封：更换为其他端口（如80,443等常见端口）
- 服务崩溃：通过SSH登录检查服务状态

FAQ

Trojan-Go 与 Trojan 有什么区别？
Trojan-Go 是 Trojan 的改进版，加入了多路复用、WebSocket 和 gRPC 支持。它兼容原版配置，同时在性能和连接灵活性上更优秀，适合多环境部署。
VLess 使用 XTLS 时证书怎么配置更安全？
推荐使用可信 CA 签发的证书（例如 Let's Encrypt），并为服务器配置正确的域名、SNI 与证书链。避免使用自签名证书或错误域名，以免被客户端拒绝或被中间人攻击检测到。
Hiddify Next 的用户管理面板有哪些功能？
Hiddify Next 面板可添加或删除用户、设置带宽限制、生成订阅链接、查看流量统计和节点状态。它提供直观的图形界面，无需命令行操作即可管理服务器资源。
WinXray 的 PAC 模式适合哪些场景？
PAC 模式通过规则动态决定流量是否走代理。适合访问国内外混合网站环境，无需手动切换节点，自动分流提高网络访问效率和连接稳定性。
Potatso Lite 如何导入 URL 格式的订阅？
在 Potatso Lite 的配置页点击“导入”，粘贴订阅链接并确认导入。系统会自动解析节点列表，可在主界面查看并选择不同线路。部分机场支持一键导入格式，省去手动配置步骤。
Quantumult X 的分流规则如何设置？
Quantumult X 通过规则分组来控制流量走向。用户可自定义策略组，将特定网站流量指向不同节点。编辑规则文件时，可利用 GEOIP、DOMAIN-SUFFIX 等指令精确管理网络行为。
Hiddify Next 如何管理用户流量配额？
管理员可以为每个用户设置上传和下载带宽以及总流量上限。超出限制可自动降速或阻止访问，保证服务器资源合理分配，提高整体网络公平性和用户体验。
SSR 节点延迟高、丢包严重，常见排查步骤有哪些？
先用 ping 和 traceroute 检查到服务器的延迟与路由跳数；再通过测速工具测带宽并尝试更换不同出站端口或混淆方式；若仍然不稳，考虑更换节点或联系客服查看服务端链路质量。
Netch 的 TUN 模式与 SOCKS 模式有何差异？
TUN 模式通过虚拟网卡拦截所有流量，更接近系统级代理；SOCKS 模式则仅作用于指定应用。TUN 模式更适合全局代理需求，而 SOCKS 模式轻量快捷，适用于游戏或单软件加速。
V2Ray 的 ws+tls 传输模式有什么优点？
ws+tls 模式利用 WebSocket 伪装成普通 HTTPS 流量，使得防火墙难以区分代理与正常访问。该模式兼容性强，适合部署在支持 Nginx 或 Caddy 的 Web 服务器上。
